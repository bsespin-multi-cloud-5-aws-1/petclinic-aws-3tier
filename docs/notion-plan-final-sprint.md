## 5. 9/18 오늘 반드시 결정 (팀 회의 30분)
1. **시연·발표 기준 환경**: (a) 지금 완전히 동작·검증된 **mc-deploy(Terraform)** 을 기준으로 발표하고 kdt5 콘솔 구축본은 "콘솔로 직접 만든 과정" 슬라이드로 활용 — 권장 · (b) kdt5 콘솔 구축본을 9/23까지 같은 구성으로 맞춤(4명이 5일 안에 재구축 → 위험). 9/16 회의록 D1(콘솔 산출물)과의 관계를 멘토에게 9/21에 확인.
2. **ASG(폭주 대응) 포함 여부**: 코드는 준비됨(`base.enable_asg`). 포함하면 9/21 apply·9/23 부하 테스트로 "증설 그래프" 한 장이 생김 / 안 하면 로드맵 슬라이드. **9/22 12:00까지 healthy 안 되면 포기**하고 로드맵으로.
3. 시연 방식: **영상 기본 + 실시간은 플랜A로만**(실패 대비 영상 필수 — OT). 시나리오 2개: A 정상 흐름(랜딩 → 앱 → owner 등록 → DB 확인 → CloudFront Hit) · B 장애·복구(WAS 1대 중단 → 알람 메일 → 서비스 지속 → 로그로 원인 → 복구) — C 보안(ALB 직접 접근 차단·WAF 차단 로그)은 캡처로.
4. 시연 담당 1명 · 화면 전환 담당(공용 노트북 1대) 1명.
5. Notion 블록 한도: 팀 문서는 **구글 드라이브 팀 폴더**(제출 필수 위치)로 옮길지 · 요금제 올릴지.
6. Bastion 허용 IP: 4명 공인 IP `/32` → `bastion_allowed_cidrs` (시연·확인용).
